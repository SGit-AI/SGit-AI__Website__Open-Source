The argument, in four infographics

Four one-page summaries of this site's argument, made for LinkedIn from the text of these pages. Each is shown here with the page it draws on and the caveat this site would attach — because a one-pager has to leave the counter-case out, and this site's rule is that the counter-case travels with the claim. Click any image for the full-size version.

Provenance. Generated with ChatGPT from the text of this site and posted on LinkedIn by the author in September 2026. The quotes on them are the author's; where an image signs a quote "Sgit", read Dinis Cruz. Released, like everything here, under CC BY 4.0.

1 · Open source is a business model

The caveat this site attaches. Three of the names on those cards — Elastic, HashiCorp and Redis — are also the relicensing cases the survivability page catalogues, and MongoDB went SSPL. The models work; what decided whether the code stayed open was not the model but the copyright structure — a single corporate holder with a CLA, in every case. So read the cards with the stress test in hand, and note that VS Code — the marketplace example — is the open-core page's strongest example of the model done well, and of its cost. And the flywheel's first spoke, "community contributes", is the one the site is most careful about: the position is that open source is the right strategy even with zero contributions.

2 · Why open source is the best commercial strategy for GenAI startups

The caveat this site attaches. Llama and Mistral are open-weight models, and the agents page is precise about the difference between that and open source AI under the OSI's definition — the distinction a browser vendor is now betting on. The strategy argument holds either way; the vocabulary matters when the buyer is a regulator. Two more things a one-pager has to leave out: the cost argument has a limit — slowness is the moat, so it only protects you from slow competitors — and the "$40B+" figure is a press valuation, which is why it appears on this site only here, labelled as such.

3 · We can't have sovereignty without open source companies and Creative Commons ontologies

The caveat this site attaches. Open source is necessary and nowhere near sufficient — that is the first row of the sovereignty page's own table of objections, and it lands fully. Having the source of a stack you cannot operate is sovereignty on paper. The capability to run and repair it still has to be bought, which is the villagers argument, and nobody currently funds the walked exit path, which is the sovereignty-bounties proposal. The infographic says "one acquisition away"; the site adds "and one SLA away".

4 · My strategy — open foundations for a more capable world

The caveat this site attaches. This one is a strategy statement from the person whose strategy it is, so it gets the treatment the about page gives itself: the interest is declared, and the two things that keep it honest are that the history is checkable without trusting the author and that the stress test is run on his own estate, in public, with the result published.
